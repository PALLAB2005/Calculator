This calculator is designed to perform basic mathematical operations through an easy-to-use interface.

## 🎯 How to Use

1. Enter a number using the calculator buttons or keyboard.
2. Select an arithmetic operator.
3. Enter the second number.
4. Press `=` to calculate the result.
5. Use `C` or the clear button to reset the calculator.

### Keyboard Controls

| Key | Function |
|---|---|
| `0-9` | Enter numbers |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `Enter` | Calculate result |
| `Backspace` | Delete input |
| `Escape` | Clear calculator |
| `.` | Decimal |
